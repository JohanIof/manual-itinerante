## Softwares Homologados

Abaixo está a lista de softwares aprovados e suas versões compatíveis.

### Sistemas Operacionais

| Software | Versão Mínima | Versão Recomendada | Status |
|----------|---------------|--------------------|---------|
| Windows | 10 (21H2) | 11 (23H2) | ✅ Homologado |
| macOS | 13 Ventura | 14 Sonoma | ✅ Homologado |
| Linux (Ubuntu) | 22.04 LTS | 24.04 LTS | ⚠️ Parcial |

### Navegadores

| Navegador | Versão Mínima | Status |
|-----------|---------------|---------|
| Google Chrome | 120+ | ✅ Homologado |
| Microsoft Edge | 120+ | ✅ Homologado |
| Mozilla Firefox | 115+ ESR | ✅ Homologado |
| Safari | 17+ | ⚠️ Parcial |

### Ferramentas de Trabalho

- **Microsoft 365** — Versão desktop e web. Conta corporativa obrigatória.
- **Google Workspace** — Acesso via navegador homologado.
- **Slack** — Versão desktop 4.35+ ou web.

## Instalação

Para solicitar instalação de software, abra um chamado no portal de TI informando:

1. Nome do software
2. Justificativa de uso
3. Aprovação do gestor direto

> **Importante:** Não instale softwares não homologados sem aprovação prévia da TI.
